# Pulse · 轻量动态广场

一个用纯 HTML + CSS + JavaScript 实现的极简社交动态应用。无需后端、无需构建工具，所有数据保存在浏览器的 Local Storage 中。

## 功能

- 发布动态（最多 280 字，带字数环与剩余字数提示）
- 按时间倒序浏览动态列表，自动刷新相对时间
- 喜欢 / 取消喜欢
- 删除动态（二次确认）
- 编辑本地昵称与用户名
- 空状态提示、Toast 提示
- 支持深浅色主题、响应式布局、`Ctrl/Cmd + Enter` 快捷发布
- 多标签页数据同步（`storage` 事件）

## 运行

直接双击 `index.html` 即可，或在项目目录启动一个静态服务器：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 文件结构

```
index.html    页面结构
styles.css    样式与主题变量
app.js        状态管理、渲染与交互逻辑
```

## 数据存储

| Key | 内容 |
| --- | --- |
| `pulse.posts.v1` | 动态列表（id、作者、内容、时间、喜欢数） |
| `pulse.profile.v1` | 本地个人资料（昵称、用户名） |

清除浏览器站点数据即可重置。
